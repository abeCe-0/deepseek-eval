# DeepSeek 输出质量评估

一个型模型输出评估项目：调用 DeepSeek API 收集回答，人工标注质量，编写规则代码自动判断，对比人工和规则的一致性。

## 项目目标

练习「模型输出评估」的完整流程：
1. 设计测试问题
2. 调用模型 API 收集回答
3. 编写标注规范
4. 人工打标签
5. 写规则代码自动判断
6. 对比人工与规则的一致率

## 项目结构

- `agent.py`：调用 DeepSeek API，收集 10 条回答
- `agent_results.csv`：原始数据
- `agent_results_labeled.csv`：带人工标签的数据
- `标注规范.md`：标注标准定义
- `auto_label.py`：规则代码 + 一致率对比
- `label.py`：标签写入脚本

## 标注规范

定义了 4 类标签：

| 标签 | 判定条件 |
|---|---|
| 格式问题 | 回答含 `**` 等 Markdown 标记 |
| 正确但啰嗦 | 事实正确 + 字数 > 100 |
| 答非所问 | 未直接回答问题 |
| 正确 | 准确、简洁、格式干净 |

## 关键结论

- **规则能处理客观特征**（如"含 `**` 就是格式问题"）
- **规则处理不了语义判断**（如"答非所问"需要理解上下文）
- **结论**：真实评估需要"规则粗筛 + 人工精判"

## 使用方法

1. 安装依赖：pip install openai pandas python-dotenv
2. 在项目根目录创建 `.env`写入API，例如DEEPSEEK_API_KEY=sk-
3. 运行 `agent.py`
